SIMBA ROARS WITH CHATS

Build Status: Complete
Build Version: 1.0

Description: Simba Roars With Chats is a messaging application created by two developers: Mbali Bukula and Siyamthemba Madinda, it converges a messaging app with a social media app and a news application which allows users to send messages to their contacts, look at the news both locally and globally, as well as join communities of likeminded people while keeping users safe online as well as being able to go to multiple links easily

Problem it solves: Simba Roars With Chats solves the problem of having to leave the current app the user is in to see the news without needing to download a dedicated news application as well as ensure users privacy is kept secret

GETTING STARTED 
Installation: On Google Play search Simba Roars With Chats and click install and after a while it will install
Alternatively, you can download APK and install it via the File Manager

SET UP
Once installed the user will be taken to the Sign Up page where they will sign up and enter their e-mail, password and verify their account, after that they will be taken to the Profile Set-Up page were the user can set up their account and go to the main activity which is the chats and the navigation bar
